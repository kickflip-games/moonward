# Moonward reference library

Design references from Moonward game-development discussions. Concept images are **not production-ready assets or validated playable geometry**.

- [Level design: 30 challenge rooms](level-design/README.md)
- [Room catalog](level-design/ROOM_CATALOG.md)
- [Art concepts, tiles, animation and environment](art/README.md)

- [Source PNG manifest](manifest.json)

**Recommended workflow:** greybox challenge rooms first; validate jumps, wall-jumps, traps and checkpoints; then apply art. Keep image references separate from active `Art/` Godot resources.

**Provenance:** The images in the level-design and art galleries are AI-generated concepts from the Moonward design conversation, not redistributions of third-party itch.io packs. External game links in `games.md` point to their creators' pages; no external art assets are stored there. The repository already contains an experimental spritesheet import in [`Art/Dungeon/`](../Art/Dungeon/README.md).
