# moonward

Itch: https://avivajpeyi.itch.io/moonward

## Engine

Use **Godot 4.8**. The current development build is 4.8-dev6; the project settings and texture import metadata are saved for 4.8. Earlier 4.5 compatibility checks are historical validation, not the project's target version.

Local development addons are optional and should not be added to the shared project autoloads or enabled-plugin list.

## Tower

The main game uses the original continuous tower, with three new sections inserted before its original scaffold shaft: **Collapsing Stair**, **Counterweight / Relay Lifts**, and **Needle Court**. The original entrance, rotating platforms, spike shafts, turrets, springboards, and moon summit remain connected. The original scaffold climb is retained above them. The tower is 2,304px taller, with thirteen checkpoints marking chapter boundaries.
